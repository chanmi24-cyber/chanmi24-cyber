## About Me

- 10년간 교육·영업 현업을 경험한 뒤 개발자로 전환했습니다.
- 요구사항 정의부터 설계, 백엔드, 프론트엔드까지 전 과정을 직접 주도해본 풀스택 개발자입니다.
- 코드를 짜는 것뿐 아니라, **왜 만드는지**를 항상 먼저 생각합니다.

<br>

## 함께 일할 때 강점

- **설계를 먼저 생각합니다** — 구현 전에 유저플로우·와이어프레임·API 명세를 직접 작성하며 방향을 잡습니다.
- **팀의 흐름을 만듭니다** — 팀장으로서 스프린트 계획, 역할 분담, 회의 진행을 주도한 경험이 있습니다.
- **현업 감각으로 소통합니다** — 비개발 직군과의 협업 경험을 바탕으로 사용자 관점에서 기능을 설명하고 조율합니다.
